# QI SYSTEM · 后勤管理系统 v0.1

一个为**内网环境**设计的轻量后勤管理系统。零第三方依赖，只需 Python 3 即可运行，用来替代日常繁琐的 Excel / Word 台账。

## 启动方法

1. 确认电脑装了 **Python 3**（命令行输入 `python --version` 能看到版本号即可）。
2. 双击 **`启动QISYSTEM.bat`**（或命令行 `python server.py`）。
3. 浏览器打开 **http://localhost:8080** 。
4. 科室内其他电脑访问：`http://本机IP:8080`（本机IP用 `ipconfig` 查看）。

数据全部保存在本文件夹 `data/qi.db`（单文件数据库），附件在 `uploads/`。**备份 = 拷贝整个文件夹**。

## 已实现模块（第一版）

| 模块 | 功能 |
|---|---|
| 📊 工作台 | 数据总览 + 到期/待办自动提醒（证件、合同、缴费、待办） |
| 🛣️ 行车记录 | 录起止公里表自动算公里数 |
| 🧮 司机补助 | 按月从行车记录**自动汇总公里、加班**，自动算补助金额、导出合计 |
| 🧑‍✈️/🚗 司机、车辆档案 | 基础台账 |
| 🏢 用房分配 | 院区/楼/房间/部门/编制人数 |
| 🪪 出入证 / 车证 | 台账 + 到期提醒 + 附件（扫描件） |
| 📄 合同管理 | 到期、缴费提醒 + 附件 |
| 💰 费用缴纳 | 水电物业等费用，应缴/已缴、到期提醒 |
| ✅ 待办事项 | 手动待办，进入统一提醒 |
| ⚙️ 系统设置 | 补助单价、提醒提前天数等 |

## 技术说明

- 后端：Python 标准库（`http.server` + `sqlite3`），**无需 pip 安装任何东西**。
- 前端：原生 HTML/CSS/JS，无需构建、无需联网。
- 架构预留了多用户（`app_user` 表），将来可扩展登录与权限。
- 数据库可平滑迁移到 PostgreSQL 以支持更多人协作。

## 目录结构

```
qi-system/
├─ 启动QISYSTEM.bat   启动入口
├─ server.py          后端服务 + 路由 + 业务逻辑
├─ db.py              数据库表结构
├─ static/            前端页面 (index.html / app.js / style.css)
├─ data/qi.db         数据库（自动生成）
└─ uploads/           附件存储
```
